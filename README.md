## 문서

## MVP 범위

1. 리치 텍스트 에디터 (마크다운 · 표 · 이미지)
2. 계층형 문서 구조 (스페이스 / 페이지 트리)
3. 권한 관리 (RBAC)
4. 버전 관리 (히스토리 · 복원)
5. 풀텍스트 검색
